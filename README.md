# Ratio Matcha — Business Website

### Project Overview

Ratio Matcha is a matcha catering business specializing in freshly prepared matcha beverages for corporate events, private gatherings, and special occasions.

As the founder of Ratio, I am developing the business website to establish its online presence and eventually provide customers with information about our services, menu, and event booking options.

This project is also an opportunity for me to apply and strengthen my web development skills while building a real website for my own business.

**Project Status:** In Progress

## Technologies

- **React** — Building the website's user interface
- **JavaScript** — Application functionality
- **Vite** — Development environment and build tooling
- **HTML & CSS** — Website structure and styling
- **Git & GitHub** — Version control and project management
- **Visual Studio Code** — Code editor
